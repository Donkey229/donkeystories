# Vloggens arbetsmapp

> Mapp: `C:\Donkeystories\projekt\vlogg` · Publicerad app: `projekt\vlog` (GitHub `Donkey229/vlog`) · Status: privat

Det här är arbetsmappen för den **privata** vloggen och minnesappen: källfiler, film och `site\`.
Allt som syns för Donkey och Emma publiceras via `projekt\vlog`, där appen ligger bakom inloggning.

## Regler
- **Privat.** Blandas aldrig med publikt eller kommersiellt material (hemsidan, Donkey Music, Donkey Lab).
- Inga bilder på Donkey och Emma tillsammans någon annanstans än här.
- Ingen länk från den publika hemsidan.
- Inga ändringar på GitHub utan Donkeys uttryckliga ja.

## Status och nästa steg
- Fyra filmer från resan (i `projekt\vlogg-import`) återstår att ladda upp. Donkey loggar in i Chrome så att uppladdningen kan göras.
- Fyll på här när du arbetar med vloggen: vad som finns i `site\` och hur den hänger ihop med `projekt\vlog`.
